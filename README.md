# 📚 Smart Library Management System

A modern full-stack Library Management System developed as a Third-Year CSE Project-Based Learning (PBL) project.

## Tech Stack

### Backend
- Node.js
- Express.js
- Prisma ORM
- MySQL
- JWT Authentication

### Frontend
- React.js
- Tailwind CSS

## Features

- Authentication
- Role-Based Access Control
- Book Management
- Student Management
- Librarian Management
- Book Issue & Return
- Fine Calculation
- Reservation System
- QR Code Support
- Dashboard & Reports

## Planned AI Features

- Semantic Book Search
- Book Recommendations
- AI Book Summary
- OCR Book Entry
- Reading Analytics
